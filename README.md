# Panelwright — published pages

The static site for [Panelwright](https://github.com/plavjanik/panelwright): the
introduction, the "Why Panelwright" argument, the making-of record and the GIBSON
3270 tour, plus captures of a real SYSVIEW screen in the VS Code panel.

Built from the `pages` branch of the panelwright repository; `index.html` is the
entry point. Sources: `docs/INTRO.md`, `docs/WHY.md`, and
`external/gibson/GIBSON-3270-TOUR.md` (on the `gibson` branch).
